# Calendarization and Phase Plan

This folder contains the project's phase planning documents and timeline.

## Contents

- **`MD2_Plan_de_Fases.md`** — Detailed breakdown of all 8 phases, dependencies, responsibilities, and the "Definition of Done" for each phase. This is the **source of truth** for what has been done, is being done, and what's left.

- **`calendarizacion_proyecto.md`** — Time-based scheduling of all phases with bi-weekly deliverables, running from August 26 through November 27, 2026. Includes a Gantt diagram and risk assessment.

## Quick reference

- **Status table** is in MD2_Plan_de_Fases.md (section 2) — update it whenever a phase changes state.
- **Branch naming convention:** `fase-N-nombre-corto` (lowercase, hyphens, no spaces).
- **Commit template** (when phase is complete): `Fase N: [nombre] — probada y terminada`
- **MVP deadline:** November 27, 2026 (phases 0–7 done and tested).
- **Optional phase 8** (custom UI) only if time permits after November 27.
